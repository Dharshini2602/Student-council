# PPG Institute of Technology Student Council Website

Official web application for the PPG Institute of Technology Student Council (PPGIT Student Council).

**Tagline:** LEAD. REPRESENT. INSPIRE.

## Features

- **Institutional Design:** Built with PPGIT brand colors (Primary Blue `#173A7A`, Secondary Green `#4C963B`, Deep Navy `#0B1730`), Anton headline typography, and Inter body text.
- **Hero & Four Primary Sections:** Fully structured homepage with high-impact hero, About & Student Voice, Events & Council Preview, and Final CTA with dot texture.
- **Events Directory & Details:** Interactive category filters, instant keyword search, upcoming/completed events, and dedicated event detail pages (`/events/:slug`).
- **Council Member Directory:** Clean grid of representatives with official designations, departments, and profile details.
- **Student Voice & Feedback:** Validated submission form for suggestions and concerns with category selection, optional anonymity, and privacy transparency.
- **About & Governance:** Institutional introduction, mission, vision, and core values.
- **Privacy & Security:** Clear information on data protection, boundaries of confidentiality, and transparent access policies.

## Technology Stack

- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + Custom CSS Variables & Design System
- **Routing:** React Router DOM v6
- **Animations:** Framer Motion (with reduced-motion accessibility support)
- **Icons:** Lucide React

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

The application will start at `http://localhost:3000`.

### Production Build

```bash
npm run build
```

This checks TypeScript types and compiles the production bundle to `dist/`.
